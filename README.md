# Camila Fontel | Advogada

Landing page de Camila Cavalcante Fontel: advocacia humanizada para famílias atípicas, mulheres e pessoas LGBTQIAPN+.

- HTML, CSS e JavaScript puros, sem build: basta abrir o `index.html`.
- Publicada via GitHub Pages.

## Antes de divulgar
Procure no `index.html` pelos placeholders destacados em amarelo (`[CIDADE]`, `[ENDEREÇO COMPLETO]`, `[UF] [NÚMERO]`, `[DIAS E HORÁRIO DE ATENDIMENTO]`, `[SEU-DOMINIO]`) e pelos comentários `REVISAR COM A ADVOGADA` / `CONFIRMAR COM A ADVOGADA`.

Este site tem caráter informativo e não representa promessa de resultado, conforme o Provimento 205/2021 da OAB.
